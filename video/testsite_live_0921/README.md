## 已知情况

- 开场没有在地址栏手输网址：第一道题由驾驶模型按题面打开测试站。
- 第 6 题的依据在视频里出现一处「[目标~2/title]」字样，是页面文字的一个内部标记没有去干净，不影响结论；本目录的记录文件已去掉这处残留，修正已进代码。
- 四处页面读取小修，都是在这个测试站上排查出来的「页面上看得见、模型收到的页面结构里却没有或不对」的问题：
  1. 被标签包住的输入框没有进入页面结构，修正前模型只能用方向键把票价一点点调出来；
  2. 下拉候选只剩一个时，外层容器被当成一行正文，和候选同字却点不动；
  3. 搜索框的标题被当成了搜索按钮；
  4. 统计卡片里没有单位的数字被当成角标丢掉，模型只能从整段文字里拆数。

  每一处都可以单独关闭，回到冻结版的行为。用 21 份真实网站的存档页面对比：前三处没有带来任何变化；第四处让其中两页多出一个原先被当成角标删掉的数字（购物车件数），其余不变。
- 发布的是录下来的这一遍完整运行；同一环境下的其他运行记录留存本机，未随本包公开。

## 题目原文

1. 打开 https://plutoyyanng.cn/ ，只看「工作台」这一页：告诉我页面上写的商品样本、模拟班次、资料公告、展示点各是多少，四个商品类别各几件；再点开右上角的「数据说明」，告诉我里面列出的三条说明。不用去其他页面核对。

2. 接着进入「商品样本」，筛选商品类别为「音频设备」、标签为「新品」的样本，按价格从低到高排列，打开其中最便宜那一件的详情页，告诉我它的参考单价、模拟库存、核心规格，以及详情页「关联资料」里那条资料的标题。

3. 接着进入「班次数据」，筛选出发城市北京、到达城市上海，按参考票价排列，打开最便宜那一班的详情页，告诉我它的班次名称、出发和到达时间、参考票价、模拟余位，以及详情页上写的开行日期。

4. 接着进入「条件查询」，查询 2026-10-01 从成都到乐山的模拟班次：最早出发 08:00、最晚出发 16:00、最高参考票价 100 元、只看有模拟余位的班次。列出每个符合条件的班次的班次号、出发时间、到达时间、参考票价和模拟余位。

5. 接着进入「资料公告」，翻到第 3 页，打开该页第一条资料，告诉我它的标题和日期；再从这条资料进入它关联的商品样本，告诉我该商品的参考单价、模拟库存和评分。

6. 最后进入「展示点信息」，告诉我成都示例展示点在公告里的特殊时段营业时间（含适用日期）、它平时的常规营业时间，以及它关联的商品样本名称。
